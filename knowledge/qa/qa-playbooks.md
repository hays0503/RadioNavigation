Q: How do I convert latitude/longitude to Unity scene coordinates for placing a marker? A: Two-step chain: `Coordinates.ToWorldPosition(lat, lon)` returns encounter-space kilometers (lon*40075.16f/360, lat*40075.16f/360), then `sandbox.EncounterToSceneSpace(encounter)` returns meters via `((p.x-o.x)*1000, 0, (p.y-o.y)*1000)` with origin `SandboxSceneOrigin.Position` (Coordinates.cs:47-55, Sandbox.cs:958-986).
Q: What coordinate pitfalls break custom map markers — wrong hemisphere placement and drifting positions? A: The `ToWorldPosition(Vector2)` overload expects `.x=lat, .y=lon` but returns `(lon_km, lat_km)` — passing (lon, lat) shifts the marker "half a map"; pass (lat, lon) as explicit doubles/floats. Never cache scene-space positions between sessions: SandboxSceneOrigin shifts, so store only lat/lon or encounter-km and recompute each frame or in `SavesManager.Loaded`. Also keep the screen-space `MaskZ(0f)` or canvas sorting breaks.
Q: What are the two ways to render a custom map marker? A: World-space: position an object at `scene.MaskY(elevationY)` above terrain, scaling by `MapController.CameraElevation` (game divides by 1400000f, EntityMarkerUI.cs:336). Screen-space uGUI: each frame project with `camera.WorldToScreenPointNonJittered(scene)`, show if `sp.z >= 0f`, set position `sp.MaskZ(0f)` — pattern from GroupMarkerUI.cs:214-216; NonJittered is mandatory because plain WorldToScreenPoint jitters under TAA.
Q: Where should I run per-frame marker visibility checks and how do I react to map display mode changes? A: Use `executionQueue.AddUpdateListener(DoUpdate)` instead of MonoBehaviour.Update() so frames stay synced with the game queue. Gate like EntityMarkersManager.DoUpdate: `mainCamera.CurrentMode == CameraMode.Map && mainCamera.isActiveAndEnabled && transform.position.y > 500f && gameUI.CurrentMode != GameUI.Mode.SoftDisabled` plus a MapDisplayMode flag check — flags are `Normal=1, Headquarters=2, WorldMap=4, TacticalMap=8, Vacation=0x10, AssignmentSelection=0x20, AssignmentSummary=0x40` (MapCameraController.cs:41-50), changes via `mainCamera.MapController.MapModeChanged` (event Action). For smooth fade use the game formula `Mathf.Clamp01((CameraElevation - 1100f) / 300f)`.
Q: How does my marker survive save/load when the game destroys entities? A: Rebuild in `SavesManager.Loaded` whose handler signature is `void Handler(Queue<Action> queue)`: destroy all child GameObjects and respawn from your own serialized data (`OnLoaded(Queue<Action> queue) => RebuildAll()`). Unsubscribe in OnDestroy (`savesManager.Loaded -= OnLoaded`) or you get NREs after scene unload — the game never serializes your marker data itself.
Q: How do I add hover tooltips to my map marker like native ones? A: Inherit `MapMarkerBase`, override `OnAwake`, implement `IPointerEnterHandler/IPointerExitHandler`: on enter `transform.SetAsLastSibling()` and enable LabelBackground; the base Title setter auto-resizes background via `label.GetPreferredValues() + (20,4)`. Set icon through `Icon` (Resource<Sprite>) — its setter calls SetNativeSize() and frees the old sprite in OnDestruct. Requires an active EventSystem.
Q: Which two modes must both match to show a panel only on the map screen? A: Both gates together, as the game itself requires (MapUI.OnEnable, GameUI.cs:473): `MainCamera.Instance.CurrentMode == CameraMode.Map && GameUI.CurrentMode == GameUI.Mode.Map`. CameraMode is a [Flags] mask — use `(CurrentMode & CameraMode.Map) != 0` for combined states, `==` for exact comparison.
Q: Should I poll camera mode every frame or subscribe to ModeChanged events? A: Polling in Update is idiomatic (game does it in TorpedoCalculatorUI.cs:148, MapUI.cs:473) and cheap for pure visibility. Use events (`mainCamera.ModeChanged += Refresh`, `gameUI.ModeChanged += Refresh`) for one-shot transitions, but note MainCamera.ModeChanged fires after the fade completes (OnModeChanged), not at SetMode call time; `RefreshCurrentMode()` can re-emit it without any mode change.
Q: How do I show fullscreen device UI like the game's instrument manuals (DeviceManualMode), including sound dimming? A: Gate on `mainCamera.CurrentMode == CameraMode.Generic && mainCamera.GenericController.ExternalController is MyDeviceController`; register your controller via `SetExternalCameraController(IExternalController, PlayableCharacter, ...)` — direct `SetMode(CameraMode.Generic)` logs a Debug.LogError (MainCamera.cs:1116). BasicDeviceController.StartController automatically calls `gameUI.SetMode(GameUI.Mode.DeviceManualMode)` and StopController restores the previous mode. For modal panels also call `[Inject] AudioController.SetFullscreenInterfaceMode(true)` on show and `(false)` on hide — tweens interior audio modifier to 0.18 over 1.5 s and back over 1 s (AudioController.cs:220).
Q: What are the three strategies for persisting mod state across UBOAT saves? A: (1) SavesManager events + your own store (PlayerPrefs/static fields); (2) put a component under the SceneObject hierarchy so the serializer writes all non-blacklisted components; (3) define a `ScriptableObjectSingleton` subclass registered via InjectIntoAssembly — GetSingletons() writes it into SaveData.scriptableObjects automatically. Static fields alone are never saved: ClassDescriptor.IsFieldSerializable drops IsStatic.
Q: Which SavesManager events do I hook to save and restore my static store, and in what order? A: Get it via `InjectionFramework.Instance.GetInstance<SavesManager>()`; load order in LoadCoroutine is `LoadingInitialization` → destroy old SceneObjects → `LoadingStarted` → worker-thread deserialization → `Loaded(Queue<Action>)`. Hook `sm.LoadingInitialization += () => reset statics`, `sm.SavingStarted += () => SaveMyStore()`, and `sm.Loaded += queue => queue.Enqueue(RestoreFromStore)` — one enqueued action = one frame, wrap each in try/catch.
Q: Which fields of a MonoBehaviour component get serialized into the save file? A: Per ClassDescriptor.CollectFields/IsFieldSerializable: public AND private instance fields are written; skipped are const (IsLiteral), [NonSerializedInGameState], static; [NonSerialized] is skipped but `[NonSerialized]+[GameStateField]` IS written. The serializer walks all GameObjects under SceneObjects via gameObject.GetComponents minus the unserializedTypes/unserializedNamespaces blacklist.
Q: What are the requirements for a ScriptableObjectSingleton that persists into saves? A: Non-abstract subclass overriding AwakeSingleton()/StartSingleton(), asset placed at `Resources/Singletons/<TypeName>`, no class-level [NonSerializedInGameState], and you must inject your assembly yourself with `InjectionFramework.InjectIntoAssembly(assembly)` — name-based auto-injection fails for mods. At load the framework Resources.Load's it and registers it injectable.
Q: Why does my restored state break even though deserialization succeeded? A: Two traps: deserialization runs on a separate LoadingThread — Unity API calls there are illegal, so read final state in a `Loaded` queue action on the main thread; and after scene change old GameObject references are fake-null (`== null` is true, ReferenceEquals(obj,null) is false) — check only via `== null`/(bool)obj and re-acquire references after load. Also call `AddSaveBlockade(this, warning)` during long async work and ALWAYS `RemoveSaveBlockade(this)`, or saves stay blocked forever.
Q: How do I read RadioStory's private stage field without getting InvalidCastException? A: The field holds a boxed private enum `RadioStoryStage` (Unknown=0, MainChoices=1, PlayMusicStation=2, LeaveStation=3, RequestResupply=4, RequestNewAssignment=5) — `(int)obj` throws InvalidCastException. Use `System.Convert.ToInt32(StageField.GetValue(story))` where StageField is resolved with `typeof(RadioStory).GetField("stage", BindingFlags.NonPublic | BindingFlags.Instance)`; stage 1 (MainChoices) is the only stage showing the decisions menu.
Q: How do I inject a custom Decision into the radio story dialog and make the UI refresh? A: Postfix `RadioStory.ContinueStory`: check `__instance.Running && ReadStage(__instance)==1`, dedup by scanning `__instance.Decisions` for your LocalizationKey, then invoke protected `InsertDecision(int, Decision)` — resolve it on `typeof(Story)`, NOT typeof(RadioStory), since GetMethod doesn't traverse base classes (declared Story.cs:377). Then invoke protected `Story.OnUpdated()` (Story.cs:438 → Updated event), otherwise the button list stays stale until the next story update.
Q: How do I construct a Story.Decision and intercept clicks on it? A: `new Story.Decision("Mod/RadioNavigation/CustomAction", null, null, "icon_name", true, (Story.Decision d) => OnMyDecision(d), index: 0, costs: new IRewardInfo[0])` — nested class Story.Decision (Story.cs:22) has readonly fields and FallbackText=null means text comes from Locale. Handle clicks with a prefix on `Story.OnDecisionSelected(Decision)` that runs your action and `return false` ONLY for your LocalizationKey, returning true for all others. Never repurpose Index — the game reads decision.Index as data (OnDecodeTransmission, OnCancelSideMission).
Q: How do I provide localized text for my injected decision and clean up between sessions? A: Patch BOTH `Locale.RetrieveString` overloads (string and string,string) with prefixes: for your key (and key+".Tooltip") set `__result` and return false, else return true — LocalizationKey in the game is a readonly field, not a property. Postfix `RadioStory.OnStopped` to clear your instance→decision cache, since the story object is recreated on every radio open and ContinueStory fires repeatedly per session (dedup is mandatory).
Q: Which GameTime events exist and how do I get current UTC time? A: DI-inject `[Inject] private static GameTime gameTime` then use `HourChanged`/`DayEnded`/`MonthEnded`/`PauseStateChanged` (all event Action), `TicksSimulated` (event Action<long>, chunks up to ~3 h of ticks), `LiveTicksSimulationStarted/Step/Stopped`, `PhysicsTimeStepChanged`. Time comes from `gameTime.GmtDateTime => new DateTime(storyTicks).AddHours(-1)` (UTC-1); also CurrentDateTime and LocalDateTime (via TimeZoneTracker).
Q: How do I watch weather values and time compression without polling? A: Weather params are `Parameter` objects — subscribe `weather.Cloudiness.Changed += OnCloudiness` with handler signature `(Parameter p)` reading `p.Value` (also Fogginess, Rain, Thunder, WindSpeed, Temperature; gameTime.TimeScale too). For compression: `timeCompressionController.TimeCompressionChanged += OnTC`, read bool `TimeCompression`, float `gameTime.TimeScale.Value`, float `gameTime.ArtificialTimeScale`; track pause via `PauseStateChanged`/`gameTime.Paused`.
Q: When should I gate lighthouse/star visibility on DarkWeather events instead of my own threshold? A: Use `weather.DarkWeatherStarted`/`DarkWeatherEnded` (event Action): IsDarkWeather is recomputed every frame as `SunZenith >= 92f || SampleAtmosphereOptimizedHDR(up).b < 0.2f || cloudiness > 0.8f || fogginess > 0.3f`, already merging night+cloud+fog semantics (IsNight is just SunZenith >= 90f).
Q: Which weather getters may return stale values up to 5 seconds? A: Everything recalculated in `Weather.LowFrequencyUpdate`, registered as `executionQueue.AddTimedUpdateListener(LowFrequencyUpdate, 5f * Random.value)`: VisualDetectabilityFactors, TotalRadioModifier, RadarDetectabilityFactors, PassiveHydrophoneDetactabilityFactors, SonicLayerDepth. Don't treat them as instantaneous; instant per-frame values are `Fogginess.Value`, `FogDensity = Lerp(0.0004, 0.02, Fogginess)`, `Cloudiness.Value`.
