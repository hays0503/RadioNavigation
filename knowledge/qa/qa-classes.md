# QA — game classes (Sandbox / Story / PlayerShip / Characters / DI+Resources)

Q: How do I convert latitude/longitude to world coordinates in UBOAT? A: `Coordinates.ToWorldPosition(float lat, float lon)` returns `(lon*40075.16f/360, lat*40075.16f/360)` (world.x=lon*k, world.y=lat*k, k≈111.3199 km/degree); the double overload uses `(float)(lon*111.3198888888889), (float)(lat*111.3198888888889)`. Inverse is `Coordinates.ToLatLong(Vector2 worldPos)` — lat from .y, lon from .x.

Q: How does Sandbox.EncounterToSceneSpace work? A: `Vector3 EncounterToSceneSpace(Vector2 encounterPos)` → `((pos.x - origin.x)*1000, 0, (pos.y - origin.y)*1000)`, origin = injected `sandboxSceneOrigin.Position`; 1 encounter unit (km) = 1000 scene units (m). `EncounterToSceneSpace2D` scales ×1000 into XY; inverse `SceneToEncounterSpace` multiplies by 0.001 and adds origin.

Q: How do I enumerate all sandbox groups and their entities? A: `Sandbox.Instance.GetGroupsDirect()` returns the live internal `List<SandboxGroup>` (never mutate; copy before iterating), each group exposes `Entities` (`List<SandboxEntity>`); `Sandbox.EncountersCount => groups.Count`. Lookups: `FindGroup(string)`, `FindPublicEntity(string)`, `GetGroupsInRange(point, range)`, `GetPublicGroupsInRange(point)`.

Q: When are groups available to a mod after scene load? A: Subscribe static `Sandbox.SandboxStarted` (fires after static groups/entities/spawners load on entering Gameplay) and instance `Sandbox.Instance.GroupAdded`/`GroupPublicityChanged`; `EntityEvacuated(SandboxEntity)` fires when crew==0.

Q: What is the radio transmission flow on SandboxEntity? A: `bool StartTransmission(RadioTransmission transmission)` rejects if !CanTransmit/null/same; sets `transmission.Source=this`, stamps `LastUpdateTicks` (gameTime.Ticks for Dynamic travel system else StoryTicks), registers in radioTransmissionsRegister, fires TransmissionChanged, and schedules timed listener UpdateTransmission (~2 s; player ship also gets per-frame UpdateTransmission2). UpdateTransmission re-checks CanTransmit, queries `sandbox.GetGroupsInRange(Position, transmission.SignalStrength*100)`, and NPC groups within DirectionFinderRange roll `gameSettings.RadioDetectionChance` → `group.AddObservation(...).AddKnownData(GroupData.TransportType, dist*0.5f*DirectionFinderInaccuracy)`; duration drains by ticks (max 40 s per step) and expiry runs HQ.ParseReport + `transmission.OnSent()` + StopTransmission unless ContinuousBroadcast.

Q: What does SandboxEntity.CanTransmit require? A: Category Empty always returns true; otherwise needs crew>0, not pacified, and healthy equipment in an equipment slot tagged "Antenna"/"U-Boat Antenna".

Q: How does a story decision get processed end-to-end? A: `StoryPlayer.SelectDecision(index)` → `currentStory.SelectDecision(decision)` → `ApplyCost(decision.Costs)` (empty stub, Story.cs:488) → virtual `OnDecisionSelected(decision)` (GenericStory stores lastSelectedDecision + AddTempTag(tail of LocalizationKey)) → `decision.CallCallback()` which prefers the `Action<Decision>` callback over `callbackAlt`.

Q: Which constructors does Story.Decision have? A: Three overloads at Story.cs :44/:57/:70: full `(string localizationKey, string fallbackText, string fallbackTooltip, string icon, bool enabled, Action callback, int index, IRewardInfo[] costs, params object[] parameters)`; short `(localizationKey, icon, enabled, Action callback, int index, IRewardInfo[] costs, params object[])` with null fallbacks; and the `Action<Decision> callback` variant. All fields readonly, Index auto = decisions.Count; LocalizationKey is a readonly field, not a property.

Q: Where are InsertDecision and OnUpdated actually declared? A: In `Story` itself, not GenericStory: `void InsertDecision(int index, Decision)` at Story.cs:377 (protected, List.Insert without renumbering Index fields) and `protected void OnUpdated()` at Story.cs:438-441 (raises `event Action<Story> Updated`). GetMethod on RadioStory.BaseType fails because Type.GetMethod doesn't traverse base classes — target typeof(Story).

Q: How do I get the player ship world position every frame? A: Cache `[Inject] private PlayerShip playerShip;` once, then per frame read `playerShip.RigidBody.position` (world-space Rigidbody position, Ship.cs:334) or `playerShip.SandboxEntity.ScenePosition2D` for map-space XZ Vector2; guard NaN before first spawn. Do not mix encounter-space `SandboxEntity.Position` (km) with scene space (meters).

Q: Is there a built-in lat/long converter I can call from mod code? A: No GeoPositionConverter exists in game source; the mod ships its own `Source/Logic/GeoPositionConverter.cs` with `DegreesPerWorldUnit = 0.008983120716174308` (=1/111.3198888888889, mirrors game WorldPosition.Latitude/Longitude): `ToLatLong(worldX, worldY)` → lat=Y·k, lon=X·k.

Q: How do I detect submarine type changes / save reloads swapping PlayerShip? A: Register once via `PlayerShipProxy.AddChangeCallback(PlayerShipChangeCallback)` (PlayerShipProxy.cs:295-302): it fires immediately with the current ship if present, then on every swap as `PlayerShipChangeEvent(previous, next)` where next==null during teardown; always unregister via `RemoveChangeCallback`. The proxy survives swaps while the PlayerShip component is destroyed/recreated — `CurrentShip` may be null mid-load.

Q: How do I check who mans the radio station? A: Resolve the station's `Activator` and read `Users` (`List<PlayableCharacter>`, self-cleaning null removal, Activator.cs:198), maintained by OnActionStarted/OnActionStopped which fire instance events ActionStarted/ActionStopped. Unpatched signal alternative: RadioUsageAction adds/removes tag "Radio Operator" on its activator at start/stop.

Q: How is role eligibility checked (e.g. Radioman)? A: `CharacterRole.IsRoleAllowedForCharacter(IPlayableCharacter)` loops requirements[] and requires `playableCharacter.Data.HasStatus(requirements[i])` for EVERY entry (CharacterRole.cs:326-337) — Radioman role is gated on the "Radioman" skill status. Relax by Harmony postfix setting `__result = true` for your condition; requirements array is private readonly-backed.

Q: What priorities/multipliers does RadioUsageAction use? A: GetSortingPriority by `character.Data.characterClass`: "Radioman"→99, "Engineer"→96, "Leader"→45, default 45 (RadioUsageAction.cs:309-324). Status "Radio Usage Practice" sets performanceReceiveMultiplier=1.33f and performanceSendMultiplier=0.67f; send duration = messages×11 s×sendMultiplier, profit halved ×0.5 when station occupied.

Q: What are the InjectionFramework [Inject] rules? A: Targets are STATIC fields only (FindMembers Static|Public|NonPublic, assigned via FieldInfo.SetValue(null,...)); resolution is exact key lookup in typeInstances — no interface/base walk on resolve side (registration registers GetType() plus all interfaces); open generics rejected with LogError; destroyed registered UnityEngine.Objects are nulled before SetValue.

Q: Why must mods call InjectIntoAssembly explicitly, and when again? A: Auto-injection filter is `assembly.FullName.Contains("uboat")` so assembly "radionavigation" never gets injected automatically — call `InjectionFramework.Instance.InjectIntoAssembly(typeof(Main).Assembly)` once after load AND re-subscribe every scene because SceneEventsListener.OnSceneAwake clears injectionsList and re-injects only "uboat" assemblies. Pattern: `SceneEventsListener.OnSceneAwake += scene => InjectionFramework.Instance.InjectIntoAssembly(modAsm);`

Q: What is the ResourceManager sync retrieval signature? A: `Resource<T> RetrieveAsset<T>(string resourcePath, object referent, bool logErrors = true)` — synchronous load usage-counted by referent; async variant `IResource RetrieveAssetAsync<T>(string resourcePath, object referent, Action<Resource<T>> onLoaded, bool logErrors = true)`. Pair every retrieval with `FreeAsset(path, referent)` or `FreeAllAssets(referent)`.

Q: How do I instantiate a prefab through ResourceManager? A: `GameObject InstantiatePrefab(string resourcePath, InstantiationFlags flags = InstantiationFlags.LogErrors)` loads then instantiates (ForceDisabled spawns deactivated), fires ICreateListener.OnCreated() on children plus ObjectInstantiated event, returns null if missing; async overload returns `UniTask<GameObject>`.

Q: What listener kinds does ExecutionQueue offer? A: `AddUpdateListener(Action)` (off-main calls buffered under lock, applied next frame), `AddLateUpdateListener(Action)` (main thread expected), `AddFixedUpdateListener(Action)` (throws InvalidOperationException off main thread), `AddTimedUpdateListener(Func<float>, delay=0f, TimedUpdatesQueue queue=Normal)` where the Func returns next delay in seconds (NaN self-removes), and `AddDateListener(Action, DateTime, ...)` serialized into savegames. Listeners run last-added-first, duplicates deduped except DateListeners; queues Normal/Continuous gate during Loading, UnscaledContinuous keeps ticking.

Q: What does ResourceLink<T> give me? A: Lazy handle: `new ResourceLink<T>("path")`; `.Asset` getter or implicit cast triggers sync `RetrieveAsset<T>` with the link as referent; `.Free()` releases usage, `.Valid` means asset != null; LoadAsync variants exist.
