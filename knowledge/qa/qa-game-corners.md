# QA - game corners not covered elsewhere (Scene.Audio / Scene.Effects / DevConsole / UserSettings / Scene.Spaces)

Q: How do I duck game audio when my mod opens a fullscreen panel (like the game does for its own UI screens)? A: Call `IAudioController.SetFullscreenInterfaceMode(bool value)` (IAudioController.cs:8, impl AudioController.cs:220) - entering tweens the interior/exterior volume scale-modifiers down to 0.18 over 1.5 s (`Tweens.Custom(interiorUIModifier.Value, 0.18f, 1.5f, ...)`, AudioController.cs:228), leaving tweens back to 1f over 1 s (line 232). Inject `[Inject] private static IAudioController audioController;`.

Q: What volume Parameters does AudioController expose for mods? A: Six `Parameter` properties - `VoiceVolume`, `MusicVolume`, `InterfaceVolume`, `InteriorVolume`, `ExteriorVolume` (each constructed as `new Parameter("...")`) plus `RoomReverb`/`Reverb` with aggregate `Parameter.Max` (AudioController.cs:42-60, exposed at 156-170). They push into AudioMixer floats on change: `"Voice.Volume"`, `"Music.Volume"`, `"Interface.Volume"`, `"Interior.Volume"`, `"Exterior.Volume"` (handlers at AudioController.cs:374-397).

Q: How does the game's Parameter/Modifier audio system work internally? A: `UBOAT.Game.Core.Data.Parameter` (Parameter.cs:13) holds named modifier lists: `AddDeltaModifier(string name)` sums and `AddScaleModifier(string name)` multiplies; both return a `Modifier` whose `.Value` you write (Parameter.cs:95/188); look up with `GetScaleModifier(name)`/`GetDeltaModifier(name)`, remove with `RemoveScaleModifiers(name)`. `Parameter.Changed` event fires on any value change (Parameter.cs:50).

Q: Which AudioMixerGroups exist and how are they resolved? A: Lazy-loaded from resource asset `"Sound Effects/Master Audio"` via `FindMatchingGroups`: Interior, Exterior, Music, Interface, Loading, External Scene (AudioController.cs:103-119). Map both ways with `GetAudioMixerGroupType(AudioMixerGroup)` / `GetAudioMixerGroup(AudioMixerGroupType)` (lines 237-279).

Q: How do game settings feed the audio mixer at startup? A: `AudioController.StartSingleton()` writes `userSettings.AudioSettings.musicVolume/speechVolume/interfaceVolume/effectsVolume` into mixer floats `"Music.Volume"`, `"Voice.Volume"`, `"Interface.Volume"`, `"Interior.Volume"`+`"Exterior.Volume"` respectively (AudioController.cs:211-218). There is no master-volume mixer float wired there - `masterVolume` is multiplied in by consumers directly (e.g. HydrophoneController.cs:170).

Q: How does a mod read the player's game settings? A: Inject `[Inject] private static UserSettings userSettings;` then use section accessors `userSettings.AudioSettings`, `.GameplaySettings`, `.ControlSettings`, `.GraphicsSettings`, `.VideoSettings` (UserSettings.cs:82-90). Without DI, resolve via `ScriptableObjectSingleton.LoadSingleton<UserSettings>()` (ScriptableObjectSingleton.cs:24), which Resources-loads `"Singletons/" + typeName`.

Q: Where is settings data stored and how do mods detect changes? A: `Application.persistentDataPath + "/settings.ubt"` with a `"-copy.ubt"` fallback load (UserSettings.cs:128-142); audio sliders live in `AudioSettings` fields `masterVolume/musicVolume/effectsVolume/interfaceVolume/speechVolume` all defaulting to 1f (AudioSettings.cs:11-19). Subscribe `UserSettings.Changed` (UserSettings.cs:111), fired by `ApplySettings(bool writeToHDD = true, bool applyGraphics = true, bool applyVideo = true, bool applyAudio = true, bool callEvent = true)` (line 184).

Q: How does the game's own lighthouse beam rotate? A: `LighthouseLight.Update()` sets `transform.localEulerAngles = new Vector3(0f, rotationOffset + gameTime.SecondsForEffects * 75f, 0f)` - a constant 75 deg/sec sweep with per-instance offset `rotationOffset = Random.value * 360f` taken in Start (LighthouseLight.cs:39,66). No Light component is driven; the visible beam is shader work: `_RotationOffset` + `_EmissionColor` pushed through a MaterialPropertyBlock onto `MeshRenderer[] lighthouseRenderers` (LighthouseLight.cs:92-106).

Q: When is the game's lighthouse lit and how bright? A: Only during dark weather - Start subscribes `weather.DarkWeatherStarted/DarkWeatherEnded` and toggles `gameObject.SetActive(weather.IsDarkWeather)` (LighthouseLight.cs:40-44,87-90); emission brightness is serialized constant `materialEmissionBrightness = 9.849155f` in dark weather, 0 otherwise, written as grayscale `_EmissionColor` (LighthouseLight.cs:26,98-100). RadioNavigation's LighthouseBeamGlow gates on the SAME signal — `isNight = weather.IsDarkWeather` (LighthouseBeamGlow.cs:975) with a sun-position heuristic fallback (:980 `isNight = sunDown`).

Q: How does the game compute lens-flare strength for the lighthouse beacon? A: Per frame it takes `Mathf.Abs(Vector3.Dot((camera.position - transform.position).normalized, transform.forward))` and sets `lensFlare.Intensity = num * num * 2f` on an `HDRPLensFlare` child, deactivating the flare GameObject when the dot product is 0 (LighthouseLight.cs:67-84) - intensity peaks when the camera sits exactly on the beam axis.

Q: What does MorseLightSignalPlayer do and how is it driven? A: A MonoBehaviour (UBOAT.Game.Scene.Effects) that blinks a serialized `Light targetLight`: `void SignalizeMessage(string message)` appends via static `Morse.TranslateToMorse(message, List<MorseSignal>)` (MorseLightSignalPlayer.cs:37-44, Morse.cs:211), `StopSignalizing()` clears and zeroes the light (line 46). Its UniTask loop advances purely on injected `IGameTime.ContinuousTicks` (not wall clock), so blinking follows game time including time compression.

Q: What are the game's morse-light timing constants? A: In TimeSpan ticks (10,000,000 ticks = 1 s): Short = 250000-tick (25 ms) fade-in, hold until `lastSignalEndTicks + 10000000`, 250000 fade-out - 1 s per Short; Long holds 30000000 - 3 s per Long; pauses: SequencePause 1 s, LetterPause 3 s, WordPause 7 s (MorseLightSignalPlayer.cs:80-205). The message loops forever (`signalIndex = 0` wrap, line 76).

Q: When will MorseLightSignalPlayer actually show signals? A: Only at night - each loop iteration checks `if (!weather.IsNight)` and keeps the light disabled/intensity 0 otherwise, polling again after a 1 s delay (MorseLightSignalPlayer.cs:67-73). `Weather.IsNight` is defined as `todSky.SunZenith >= 90f` (Weather.cs:623); `IsDarkWeather` property and `DarkWeatherStarted/DarkWeatherEnded` events sit at Weather.cs:621,677,679.

Q: What is the exact API to add a dev-console command? A: Static `DevConsole.AddListener(string command, Action<string[]> listener)` stores into a static dictionary, silently replacing any existing entry (DevConsole.cs:97-100). Handlers match `private static void Budget(string[] arguments)` style; the game registers dozens in one block, e.g. `DevConsole.AddListener("Teleport", Teleport)` (DevConsoleCommands.cs:170-184, handler at :878).

Q: How does DevConsole tokenize and dispatch a submitted command line? A: Static `Submit(string cmd, bool addToHistory = true)` regex-parses `([^ "]+)|(?:"(.*?)")` so quoted args stay together, then looks up token[0] in the listeners dict and invokes it with the full string[] (DevConsole.cs:165-210). First console use pops a confirmation that sets `playerCareer.IsPlaythroughLockedOutOfAchievements = true` (lines 176-180, 223-226); history (max 10) persists under PlayerPrefs key `"DevConsoleCommands"` (lines 238-261).

Q: Why might a mod-registered console command never fire? A: The toggle key only works when `GameDataReference("General/Settings/System/Enable Developer Console").GetBoolean()` is true and `gameUI.CurrentMode != GameUI.Mode.Disabled` (DevConsole.cs:60,113); unknown commands just log `"Invalid command!"` (line 208). Also note opening the console freezes game time via `gameTime.TimeScale.AddScaleModifier("DevConsole").Value = 0f` (line 121).

Q: How do I map a position from the ship-interior virtual scene to the main outdoor scene? A: `PlayerShipInterior.GetMainScenePosition(Vector3 containerPosition)` subtracts `verticalOffset` (= interior prefab world Y captured in Awake, PlayerShipInterior.cs:92) then applies `playerShip.transform.TransformPoint(...)` (lines 214-218); inverse `GetContainerPosition(Vector3 mainScenePosition)` uses `InverseTransformPoint` and adds the offset back (225-230). Rotations pair as `ship.rotation * q` / `q * Quaternion.Inverse(ship.rotation)` (220-235).

Q: Is there a shared interface for these coordinate conversions? A: Yes - `ITransformContainer` with the four GetMainScene*/GetContainer* methods; `MainSceneContainer.Instance` is the identity implementation (MainSceneContainer.cs:5-29) and `TransformContainerListener.Awake()` resolves the container via `GetComponentInParent<ITransformContainer>()`, falling back to MainSceneContainer when null (TransformContainerListener.cs:17-33); get one anywhere with static `TransformContainerListener.GetInstance(Transform)`. Related helpers on PlayerShipInterior: `InteriorToWorld(Vector3)` (188-192) and per-frame global shader matrix `_InteriorToWorld` set to `playerShip.transform.localToWorldMatrix` (line 211).
