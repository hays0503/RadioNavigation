Q: What does RadioInstaller.Instantiate wire up on the radio prefab? A: Source/UI/RadioInstaller.cs ensures root components RadioHandler, CanvasGroup, PanelDragHandler, then adds handlers to children by PrefabNames constants — CursorHandler on "CursorSpinner" (fallback "Cursor"), ToggleHandler on "Toggle", GroundHandler on "Ground", ExpanderHandler on "Expander", ZoneHandler on "RadioZone", VolumeSpinnerHandler/FeedbackSpinnerHandler on their spinners, plus SonneController (with a new AudioSource if absent), InformationPanelHandler and ChronometerOverlayHandler on the root.
Q: In what order does RadioInstaller attach components and where does the panel end up? A: Root components first (RadioHandler, CanvasGroup, PanelDragHandler), then children top-down (Cursor, Toggle, Ground, Expander, RadioZone, VolumeSpinner, FeedbackSpinner, DebugAnglePanel last), then SonneController+AudioSource, InformationPanelHandler, ChronometerOverlayHandler; finally it reparents to the viewport with SetParent(viewport,false) and centers it via localPosition = Vector3.zero (F188 fix for off-screen at low resolutions).
Q: What is the signature of RadioHandler.OnFrequencyChanged? A: It is a static event `Action<float, int>` (Source/UI/RadioHandler.cs:12) carrying frequency in kHz and the current zone index, emitted from EmitFrequency whenever CursorAngle changes or OnZoneChanged fires; subscribers include InformationPanelHandler and SonneController wiring.
Q: How does RadioHandler.IsVisible work? A: IsVisible toggles a private serialized bool and drives the CanvasGroup — alpha 1/0, interactable, blocksRaycasts all set to the value (Source/UI/RadioHandler.cs:37-55); Start forces it false, Escape closes the panel in Update unless selection lies outside the panel (F133).
Q: How does RadioHandler convert cursor angle into a frequency? A: EmitFrequency computes `currentAngle = cursorAngle + Constants.CursorOffsetDeg` (=90f, Source/Logic/Constants.cs:31) and feeds it through DialConfig.AngleToFrequency(currentAngle, currentZoneIndex), then fires the static OnFrequencyChanged(freq, zoneIndex).
Q: Why does RadioHandler.CursorAngle use Mathf.Approximately? A: The setter skips emission when the new value equals the old within float tolerance because lerp-smoothed spinner angles can differ only by rounding, which would otherwise re-emit or skip events spuriously (F147, Source/UI/RadioHandler.cs:26-32).
Q: Where is the global radio-on state kept? A: In ToggleHandler's static volatile field backing IsRadioOn (Source/UI/ToggleHandler.cs:17-21); it is set in OnToggleChanged, combined with groundActive into static IsInteractable (`IsRadioOn && groundActive`), and all three statics are reset to false in OnDestroy (F61) so UI state never leaks across scene loads.
Q: Which handlers check ToggleHandler.IsInteractable before acting? A: SpinnerHandlerBase (OnBeginDrag/OnDrag), CursorHandler (OnBeginDrag/OnDrag/OnScroll/Update), PanelDragHandler (OnBeginDrag, F198) and ZoneHandler.CanSwitchZone all early-return unless ToggleHandler.IsInteractable is true, so nothing responds while radio is off or ground is inactive.
Q: How does ZoneHandler validate zone indices? A: SetZone ignores any index when zoneImages is null, negative, or >= ZoneNames.Length (5 zones "Zone1".."Zone5", F15 restore no-op guard); SetAlpha additionally guards via IsInvalidZoneIndex against the zoneImages array length, while NextZone/PreviousZone wrap with modulo arithmetic.
Q: How do zone clicks cycle zones in ZoneHandler? A: Each zone child gets an EventTrigger with a single PointerClick entry (F118 avoids double callbacks): Left button calls NextZone, Right button calls PreviousZone; switching requires parentTransform alive and ToggleHandler.IsInteractable, and each change hides the old image, shows the new one, and fires OnZoneChanged(int).
Q: How does SpinnerHandlerBase compute the drag angle? A: OnDrag takes dir = pointer position − spinner center, rejects negative y via HandleDragDirection, computes Atan2(dir.x, dir.y)*Rad2Deg + GetAngleOffset() (default 90°), clamps via ClampTargetAngle to [minAngle, maxAngle] (serialized defaults 0..140), then lerps toward it frame-rate independently with t = 1 − Exp(−sensitivity·deltaTime·60) when UseSmoothing() is true (F72).
Q: When does SpinnerHandlerBase raise OnValueChanged? A: From OnAngleUpdated after every drag tick that passes the direction filter, after SetAngle restores a persisted angle (clamped, applied as rotation), and not at Awake which only clamps startAngle silently; VolumeSpinnerHandler and FeedbackSpinnerHandler inherit this unchanged except FeedbackSpinnerHandler adds DEBUG logging.
Q: How does SpinnerHandlerBase avoid stuck drags? A: Drags track an activePointerId captured in OnBeginDrag and matched by IsActiveDrag; OnEnable resets isDragging and activePointerId = -1 so a mid-drag disable that skips OnEndDrag (F149) cannot lock out future drags. PanelDragHandler uses the same pattern in OnDisable.
Q: What angle offset does CursorHandler apply? A: None itself — it writes raw angle = Atan2(dir.x, dir.y)*Rad2Deg (clamped implicitly by drag geometry, negative y floored to 0) into RadioHandler.Instance.CursorAngle and rotates localRotation by −angle; the +90° Constants.CursorOffsetDeg correction happens later inside RadioHandler.EmitFrequency. Scroll adjusts CursorAngle by delta*step (ScrollStepNormal 3f, ScrollStepFine 0.5f with Ctrl) clamped to [MinAngle=-90, MaxAngle=90].
Q: What gates dragging the whole panel? A: PanelDragHandler.OnBeginDrag accepts only Left button, requires ToggleHandler.IsInteractable (F198), and bails if the pressed object belongs to ExpanderHandler, ChronometerOverlayHandler elements, or has ZoneHandler/ToggleHandler/GroundHandler in its parents (F207 — child controls resolve drags to the panel root); OnDrag then moves anchoredPosition by eventData.delta / canvas.scaleFactor.
Q: How does PanelDragHandler manage the move cursor? A: OnPointerEnter sets a procedurally generated 32×32 crosshair texture (cached statically, hotspot (16,16)) unless a chronometer zone owns the pointer (SetChronometerPointerInside) or a drag is active; OnPointerExit keeps the cursor during fast drags (F187); SetCursorOverride/ClearCursorOverride let other systems swap it, and OnDestroy destroys the cached texture to avoid GPU leaks (F42).
Q: What does InformationPanelHandler display? A: It builds labels under InformationPanel/ScrollView/Viewport/Content showing toggle ON/OFF, ground Active/Dimmed, zone number, volume and feedback percentages (angle/140*100), formatted frequency with band id, closest station name (zone index 1 only, within Constants.StationMatchDeltaKHz = 20 kHz, Gaussian gain exp(−d²/4.5)), a rich-text signal line refreshed every 0.15 s (SignalUpdateInterval), decoded morse text, and per-station pattern lines refreshed every 0.5 s (PatternUpdateInterval).
Q: How does InformationPanelHandler consume SonneController diagnostics? A: UpdatePatterns iterates sonneController.StationCount calling GetStationDiagnostics(i), skipping stations with Gain < 0.001, and renders Callsign, InBeam ("IN BEAM"/green vs gray), BeatFrequency, Gain%, SchedulerPhase, BearingToBoat, SectorNumber with DASH/DOT, EqSignIndex, DotCount/DashCount, CurrentBearing, and for the DominantStationIndex also GetReceivedNavigationDotCount/GetReceivedNavigationDashCount; NavigationElapsed renders as mm:ss, and dominant station phase is appended to the station label (F101 guards domIdx < 0). Outside IsInSonneZone it clears patterns and grays the signal line.
