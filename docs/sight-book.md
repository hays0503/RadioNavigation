# Книга расчётов — текстовый экспорт

Реализация 2026-11-12. Интерактивная книга пока не внедрена.

## Файл и события

`sight-book.txt` находится в каталоге мода:
`Application.persistentDataPath/Mods/RadioNavigation/sight-book.txt`
(Windows: `%USERPROFILE%/AppData/LocalLow/Deep Water Studio/UBOAT/Mods/RadioNavigation/sight-book.txt`).
Это LocalLow, **не** каталог `UBOAT.exe`. UTF-8 BOM, CRLF, перезапись, не append.

- Первый успешный `I` создаёт книгу. Каждый следующий успешный замер заменяет её
  текущими слотами серии. Отклонённые замеры не пишут.
- `O` заменяет начатую книгу пустой серией. До первого замера `O` файл не создаёт.
- Загрузка сохранённой непустой серии экспортирует её. Загрузка пустой серии
  после начатой книги убирает старые наблюдения из файла, в том числе оставшегося
  от предыдущего процесса игры. Контроллер передаёт факт существования файла
  при создании worksheet; файловых проверок в каждом кадре нет.
- Открытие/закрытие прибора, 1 Гц карточка и кадры не пишут файл.
- Ошибка каталога/прав не отменяет замер; writer возвращает ошибку, вызывающий
  слой предупреждает один раз через `WarnOnce`.

`SightBookFileWriter` не зависит от Unity: целевой каталог передаёт контроллер.
`SextantWorksheet` принимает sink для офлайн-проверки действительного пути захвата.
Производственный sink всегда подключён в `SextantController.Awake`.

## Содержание

Каждая страница ограничена отдельными строками `=====Начало=====` /
`=====Конец=====`. Книга содержит инструкцию, отдельный полный разбор каждого
из трёх возможных наблюдений, страницу FIX/ожидания и справочную страницу.
Солнце, Луна, звёзды и смешанные серии используют одинаково развёрнутую цепочку;
страница звезды не отсылает к странице Луны.

Карточки: «Возьми → Сделай/Найди → Запиши → Проверь → Дальше».
Символ поясняется рядом со значением, например
`Hs(отсчёт барабана, до поправок)`. Нужные входы повторяются.

- Солнце: сырой отсчёт → поправка нуля → реальные клетки/веса F VIII →
  месяц → исправленная высота → четырёхчасовая строка SH5 → GHA/склонение.
- Луна/звёзды: явно обозначенная инструментальная модель мода, сохранённая
  эфемерида, гринвичский и местный часовой угол. Лунный параллакс не вносится
  повторно. Каталог звёзд — эпоха 1926.0 с прецессией.
- Все светила: точка расчёта → местный угол → вычисленные высота/азимут →
  разность высот в минутах → интерцепт → направление и точка линии положения.
- FIX: перенос каждой линии к общему моменту, предупреждение о старой скорости,
  способ решения, вершины/стороны/площадь/радиус из **одного** результата
  `CockedHatResult`, замороженное опубликованное место и самопроверка.
  При fallback на пару подробные карточки переноса не выводятся: решатель не
  возвращает выбранную пару и момент её FIX. Перенос всех трёх линий к последнему
  замеру нельзя выдавать за объяснение опубликованного результата пары.
- Справка: табличные и инструментальные поправки отдельно; современная
  сферическая формула только для проверки. Уже вычисленные угловые минуты
  повторно на 60 не умножаются.

## Источник чисел и ограничения

Основные значения читаются из `SextantObservation` и опубликованного состояния
worksheet. `FixCardComposer` — соседний форматтер, не источник навигационных данных.
Поставщик текущего мода даёт игровую позицию: книга не называет её результатом
ручного счисления и не меняет на удобную принятую точку без нового расчёта.

`TryDetails` в F VIII/SH5 раскрывает те же клетки/строки и веса, которые использует
расчёт. При экспорте старой записи это **сверка с текущей версией пакета**, не
обещание сохранённой исторической provenance. Основные числа не подменяются.

F I/F II/F XI **не оцифрованы**. Вместо статических подогнанных «клеток» прежнего
черновика книга показывает честный переход к сферическим h1/Az мода. Это
не полный бумажный справочник со всеми ветвями таблиц и не доказательство
исторического использования игрового сборника SH5. Учебный пример A и прежняя
несогласованная серия B не вклеиваются в живую серию. Числовой треугольник
проверяется в тесте на одном действительном вызове решателя, без выдачи
синтетической серии за наблюдения игрока.

Формат сейва остаётся **v3**:

- сырой отсчёт Луны/звёзд не сохранён; книга пишет «нет данных», не обращает
  квантование назад и не придумывает отсчёт;
- новый подробный текст FIX держится до следующего замера/reset в памяти;
  загрузка экспортирует прежний опубликованный текст и координаты, но не
  пересчитывает FIX и не подставляет текущую скорость;
- идентификаторы выбранной пары и внутренние проходы решатель не возвращает;
  книга обозначает это, а не имитирует полный trace;
- v4 provenance, патрульный журнал, интерактивное листание и режим «Штурман»
  остаются следующими этапами.

## Проверка

реальные F VIII/SH5 входы примера A, направления интерцепта, все тела,
треугольник из одного решателя, frozen/legacy, BOM/CRLF/overwrite/I/O-отказ.
Файлы явно зарегистрированы в тестовом csproj.

Уточнения по ревью 2026-11-14:

- Поля SideANm/SideBNm/SideCNm — расстояния AB/BC/CA между именованными вершинами,
  не стороны напротив вершин A/B/C. Подписи F5 и повторные входы F6 исправлены;
  тест измеряет каждую пару вершин, а не только перестановочно-инвариантную площадь.
- Fallback больше не печатает недоказанный перенос к моменту третьего замера.
  Регрессия исполняет путь worksheet с ненулевым ходом и вынужденной парой 1/2;
  отдельный тест сохраняет все три карточки переноса для центроида.
- UT печатается с семью знаками дробной секунды (точность DateTime), высота
  глаза — с шестью десятичными знаками в обоих входах. Вес глаза остаётся F4.
  Проверен случай с дробной секундой и высотой 5.123456 м, включая повторные входы.
- Это изменения представления книги, не решателя, формата save v3 или геометрии карты.

обычный успешный `I`, затем второй/третий замер, `O` и save/load. Деплой требует
отдельного разрешения на перезапуск игры.
