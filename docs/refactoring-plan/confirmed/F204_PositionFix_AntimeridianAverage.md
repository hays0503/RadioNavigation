## Описание

`FindIntersection` корректно нормализует долготу каждой точки пересечения к [-180, 180] (`PositionFixCalculator.cs:198`):

```csharp
float lon3 = (float)((lam3 * (180.0 / Math.PI) + 540.0) % 360.0 - 180.0);
```

Но оба этапа агрегирования усредняют долготы **как линейную координату**:

```csharp
// PositionFixCalculator.cs:49-57 — грубый центроид
float roughLat = 0f; float roughLon = 0f;
for (int i = 0; i < rawIntersections.Count; i++)
{
    roughLat += rawIntersections[i].Latitude;
    roughLon += rawIntersections[i].Longitude;
}
roughLat /= rawIntersections.Count;
roughLon /= rawIntersections.Count;

// PositionFixCalculator.cs:94-110 — взвешенный финал
totalLon += wp.Longitude * wp.Weight;   // ...
float calcLon = totalLon / totalW;
```

Если валидные пересечения лежат по разные стороны дата-лайна (+179° и −179°), среднее даёт ~0° — фикс прыгает на противоположную сторону земного шара. Тот же эффект искажает веса: `GetDistanceKm(m.Longitude, roughLon)` (`:62`) считается от неверного центроида.

---

## Влияние

- Latent сегодня: недостижим, пока не исправлен F200 (все пеленги из (0,0) дают пересечения в Атлантике).
- Станет реальным при подключении реальной позиции лодки и игре у ±180° меридиана (Алеутские о-ва, Новая Зеландия — регионы действий тихоокеанских U-Boat).
- Не покрыто: **F128** документирует только не-нормализацию `deltaLam` внутри `FindIntersection`; об усреднении долгот в `Calculate` нет ни слова.

---

## Сценарий воспроизведения

1. (После фикса F200) Лодка на 179.5°E; две пары станций дают пересечения +179.8° и −179.9°.
2. `roughLon` и `calcLon` ≈ 0° → фикс показывает 0°E (ошибка ~19 900 км), веса пар искажены.

---

## Исправление

Нормализовать усреднение по окружности — усреднять как комплексные единицы (векторный mean), затем `atan2`:

```csharp
double sumX = 0, sumY = 0;
for (...) { sumX += Math.Cos(ToRadians(lon)); sumY += Math.Sin(ToRadians(lon)); }
double meanLon = Math.Atan2(sumY, sumX) * 180.0 / Math.PI;
```

Применять в обоих местах (грубый центроид `:49-57` и взвешенный `:94-110`). Для расстояний с неверным центроидом (`:62`) средняя долгота теперь корректна автоматически.
