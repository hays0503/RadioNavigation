## Описание

Коэффициент усиления станции (`UpdateStationGains`, `SonneController.cs:363-364`):

```csharp
float ratio = f / f0 - f0 / f;                                  // расстройка
float gain = 1f / (float)Math.Sqrt(1.0 + qf * qf * ratio * ratio);
```

с дефолтным `QualityFactor = 20f` (`AudioSynthesisEngine.cs:25`; минимум в `ApplyFeedback`, `:44`: `20f + Feedback²·180f`) даёт 3 дБ-полосу примерно ±6.6 кГц.

Станции в `BeaconData` разнесены всего на 1-20 кГц (266, 257, 319, 285, 315, 332.5×3, 307, 306, 481×2, 316 кГц). Расчёт для дефолтного QF=20:

| Настройка | Сосед | Расстройка | ratio | Gain |
|-----------|-------|-----------|-------|------|
| 307 кГц | 306 кГц | 1 кГц | 0.0065 | **~99%** |
| 316 кГц | 315 кГц | 1 кГц | 0.0063 | **~99%** |
| 266 кГц | 257 кГц | 9 кГц | 0.0689 | **~59%** |
| 306 кГц | 315 кГц | 9 кГц | 0.0678 | **~60%** |

Микшер `ProcessAudio` (`AudioSynthesisEngine.cs:132-140`) суммирует **все** станции с `Gain ≥ 0.001`:

```csharp
if (stations[s].Gain.IsNegligible(0.001f)) continue;
if (keyers[s].KeyOn) sample += stations[s].Gain * carriers[s].NextSample();
```

Дополнительно `BeatFrequency = clamp(1000 + offset·1000, 300, 1800)` (`SonneController.cs:368-370`): станции, расстроенные более чем на ~0.7-1.3 кГц, всё равно дают слышимый бит-тон на 300/1800 Гц — фильтрация по тону отсутствует.

### Итог

Игрок слышит **два морзе-потока одновременно** (соседние станции с сопоставимой громкостью), при этом экранный декодер/сигнал (`SignalRichTextFormatter`, доминирующая станция в `SonneController`) показывает только одну. Аудио- и визуальная информация расходятся; счёт точек (F201-сценарий) читается на фоне чужих передач.

Только выкручивание ручки Feedback до максимума (QF=200) снижает соседнюю станцию до ~7% (для расстройки 9 кГц) / ~30% (для 1 кГц) — но дефолтное состояние наименее селективное.

---

## Влияние

- Каждая сессия в Sonne-зоне до регулировки Feedback.
- Мешает чтению навигационной передачи (точки/тире), ухудшает декодирование позывного.
- Расхождение «что слышно» vs «что показано» на панели сигнала.
- Не покрыто: **F142/F143** — про неклампированный выход DSP (другой уровень), **F40/F141** — про верхнюю границу частоты несущей, **F39** — про три станции на 332.5 кГц (дублирование частот — отдельная проблема данных).

---

## Сценарий воспроизведения

1. Войти в Sonne-зону с дефолтной ручкой Feedback в 0.
2. Настроиться на 307 кГц (станция 1) — передачу станции на 306 кГц слышно на ~99% громкости.
3. На панели сигнала отображается только доминирующая станция — аудио содержит обе.

---

## Исправление

1. Поднять дефолтную избирательность: `QualityFactor` стартовать с ~100-200 (либо сделать зависимость от расстройки: усиление по лоренциану уже есть, но полоса слишком широка).
2. Опционально: в миксере учитывать только станции с `Gain` относительно доминирующей (например, `gain > 0.5·maxGain`), либо выводить бит-тон только для доминирующей станции, а остальным давать «шумовую маску».
3. Проверить согласованность с экранным сигналом (что слышно = что показано).

## Зависимости
