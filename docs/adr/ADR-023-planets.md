# ADR-023: Планеты в STAR_SKY

> Статус: Accepted (2026-08-19)  
> Связи: `STAR_SKY_PLAN.md`, `Source/Logic/AstroMath.cs`, `Source/Logic/PlanetRenderer.cs`

## Контекст

- STAR_SKY должен показывать четыре яркие планеты, доступные для визуальной навигации.
- Нужны геоцентрические RA/Dec на эпоху даты и единый pipeline ENU/camera с каталогом звёзд.

## Решение

- `AstroMath.PlanetRaDec` использует средние кеплеровы элементы для 1800–2050.
- Для Венеры, Марса, Юпитера и Сатурна учитываются эксцентриситет, наклонение орбиты и восходящий узел.
- Гелиоцентрические эклиптические координаты переводятся в геоцентрические экваториальные координаты через наклонение эклиптики.
- `PlanetRenderer` создаёт один mesh из четырёх camera-facing quad и переиспользует `CameraResolver`, `GamePlayerPositionProvider`, `LstDeg` и `RaDecToEnu`.
- Планеты скрываются без камеры или игровой позиции; ниже горизонта quads не создаются.

## Ограничения

- Модель не включает световое время, возмущения, аберрацию и полные VSOP87-коэффициенты.
- Точность подходит для визуального слоя и грубой навигации, но ещё не подтверждает требование ≤1′ из STAR_SKY_PLAN.
- Время пока берётся из `DateTime.UtcNow`; интеграция `GameTime.GmtDateTime` остаётся отдельной задачей.

## Проверка

- 206 тестов проходят.
- Проверены конечность RA/Dec, диапазоны координат, отклонение склонения от нуля и отказ для неизвестного planetId.
