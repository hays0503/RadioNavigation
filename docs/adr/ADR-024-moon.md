# ADR-024: Луна в STAR_SKY

> Статус: Accepted (2026-08-19)  
> Связи: `STAR_SKY_PLAN.md`, `Source/Logic/AstroMath.cs`, `Source/Logic/PlanetRenderer.cs`

## Решение

- Добавить `MoonRaDec` на основе упрощённых орбитальных элементов Meeus/low-precision.
- Переводить лунные эклиптические координаты в экваториальные через наклонение эклиптики.
- Рендерить Луну в том же mesh, что и планеты, отдельным пятым camera-facing quad.
- Использовать синодический период для освещённости: `0.5 * (1 - cos(phase))`.
- При нулевой освещённости alpha quad становится нулевой.

## Ограничения

- Это не усечённый ELP2000 и не подтверждает требование точности около 10″.
- Не учитываются полные лунные члены, оптическая либрация, аберрация и световое время.
- Перед заменой игровой Луны нужна Phase 0 проверка на датах 1942-06-15 и 1943-01-10 в 00:00/06:00 UT.
- Текущее время берётся из `DateTime.UtcNow`; подключение `GameTime.GmtDateTime` остаётся отдельным этапом.

- 208 тестов проходят.
- Проверены конечность RA/Dec и противоположные значения освещённости новолуния/полнолуния.
