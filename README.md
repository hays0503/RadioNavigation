# RadioNavigation

Мод для UBOAT: радионавигация Consol/Sonne, звёздное небо и секстант.

- **Версия:** 2.1
- **Автор:** testui
- **Namespace:** `UBOAT.Mods.RadioNavigation`

## Возможности

- Панель радио: включение приёмника, переключение наземного/секторного режима (ground/zone), настройка громкости и обратной связи
- 5 исторических станций CAP 59, 5 диапазонов настройки; сигналы синтезируются DSP-кодом (`OnAudioFilterRead`, без аудиофайлов)
- Декодирование позывных азбукой Морзе, анализ сигнальных паттернов
- Секстант: ручное счисление позиции по Солнцу, Луне и звёздам (бланк F-Tafel)
- Каталожное звёздное небо, созвездия, маяки и нативные метки карты

## Ручное счисление (секстант)

- **Z** — открыть/закрыть в живом виде FPP/SectionView (не на карте и не в FreeFly). Внутри лодки окуляр показывает интерьер, опознание неба заблокировано. Снаружи наведите светило в центр и держите 2.5 с — появится имя. Конус опознания — 1° при любом зуме; после выхода из него выбор удерживается до 5 с.
- **I** — записать текущий отсчёт барабана для выбранного тела. Второй замер даёт FIX, третий — треугольник линий положения; последующие заменяют **№3**, не №2. Разброс авто-замеров — показатель качества, не замена отсчёта по I.
- **O** — новая серия и сброс выбора; **P** — справка по F-Tafel и управлению.
- Правая колонка показывает доступные светила, высоты/азимуты, состояние Луны и рекомендации пары/тройки. Планеты видны на небе, но в счислении не участвуют.
- FIX и вершины LOP — нативные точки карты. Уничтожение самой точки не стирает расчёт или карточку; новое I/O снимает подавление меток. Физическое удаление ластиком/Delete ещё не подтверждено: текущий перехват сохраняет все `RadioNav`-точки и удаляет связанные фигуры (`MAP_MARKERS_PLAN.md`). «Δ от места игры (проверка)» — самопроверка замеров, а не навигационная необходимость.

| Клавиши при открытом секстанте | Действие |
|---|---|
| ↑/↓, Shift+↑/↓ | Дуга 2°/с, с Shift — 10°/с |
| Ctrl+↑/↓ | Один квант дуги: 0.1′ (6″), с повтором при удержании |
| ←/→, Shift+←/→, Ctrl+←/→ | Горизонтальная подстройка: 2°/с, 10°/с или шаг 0.05° |
| +/− (также цифровой блок) | Зум ×1…×6; исходный — ×1 |
| R | Сброс дуги и горизонтальной подстройки |
| 0/1/2/3, Ctrl+0/1/2/3 | Фильтры правой / левой половины |
| 4 | Вставить/убрать линзу Sternspreizglas в правой половине |
| C / Shift+C | Записать / очистить индексную поправку; C требует тело в конусе и пустую серию |

**Допущения:** рефракция и dip не вносятся в замер. Топоцентрический параллакс Луны учтён согласованно в рендере, опознании и редукции; в справке указан остаток ±0.1°, не гарантия точности FIX. Звёзды прецессируются от фактической эпохи каталога 1926.0 к дате игры (старый заголовок J1942 неверен). Солнце/Луна используют общую калибровку времени Δt, звёзды — UTC. Подробности: справка по **P**, `CELESTIAL_REALISM_PLAN.md`, ADR-033.

Вне секстанта **Shift+Z** переключает созвездия. Дуга и зум переживают закрытие, фильтры сбрасываются. Активная серия (до трёх наблюдений), карточка, FIX/LOP и скрытие маркеров сохраняются **в выбранный игровой сейв**; drag-позиции и фигуры — в его нативную БД карты. Старые безымянные точки сохраняются, но отсутствующие исходные наблюдения из них не восстанавливаются. Контракт и игровая приёмка — `docs/astro-save.md`.

## Установка

Скопировать папку мода в каталог `UBOAT/Mods/`, включить RadioNavigation в списке модов и подтвердить разрешения скриптового мода. Игра компилирует `Source/**/*.cs` при загрузке; заранее собранная DLL не требуется.

Требуется AssetBundle `Bundles/testui` (префабы, материалы, шейдеры и иконки). Если префаб не пройдёт валидацию, панель отключается без падения игры. После изменения исходников нужен перезапуск игры; hot-reload не заменяет сборку и загрузку нового кода.

## Сборка и проверки

Нужна установленная UBOAT с игровыми/Unity DLL. Основная сборка — raw `csc` из `build.ps1`, с C# 7.0 и блокирующим PVS-Studio. .NET SDK нужен для офлайн-тестов и анализа, а не для поставки DLL в игру.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -Configuration Release
powershell -ExecutionPolicy Bypass -File build.ps1 -Configuration Debug
powershell -ExecutionPolicy Bypass -File gates.ps1
dotnet run --project RadioNavigation.Analyzers.Tests -c Release
```

`gates.ps1`: build → SourceCheck + quick analysis → tests → PVS; `-Parallel` запускает независимые линии. Отдельно: `tests.ps1`, `dotnet run --project RadioNavigation.SourceCheck -c Release`. Нестандартный путь игры задаётся `build.ps1 -GamePath "<путь>"`.

**Деплой разработчика:** `run-game.ps1` (обёртка `deploy-radionav.ps1`) обновляет timestamps исходников обоих модов и перезапускает игру для её собственной компиляции. Скрипт завершает работающую игру и загружает последний сейв — применять только с разрешённым тестовым состоянием. **Не копировать DLL в `Temp`**: этот кешированный путь может молча пропустить инициализацию. Подробности — `docs/CAMERA_GUIDE.md` §12.

## Структура репозитория

- `Source/` — код мода: `Data/` (конфиги маяков/диапазонов), `Logic/` (ядро: морзе, паттерны, пеленги), `Sound/` (DSP-синтез), `UI/` (обработчики uGUI)
- `Tests/` — офлайн-тесты (Unity-зависимости заменены stubs; не GPU-приёмка)
- `SAD/` — документ архитектуры (11 глав; приложения A–C и старый roadmap — в `archive/`)
- `refactoring-plan/` — аудит: 241 находка F001–F243, статусы в `hypothesis/INDEX.md`, неисправленное в `DEFERRED.md`
- `docs/adr/` — 21 решение (ADR-014…ADR-034); сводка статусов в `SAD/12_Architecture_Decisions.md`
- `knowledge/` — скомпилированная база знаний по API игры UBOAT
- `DESIGN.md` — спецификация радиопанели (не всего мода)
- **`DOCS.md` — карта всей документации: что читать и для чего** (начните отсюда)
