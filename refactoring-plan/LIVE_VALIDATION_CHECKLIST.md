# Чек-лист live-валидации (Фаза 3) — RadioNavigation v2.0.0

Проверки в игре после всех рефакторингов аудита (F01–F207) и deferred-code (F12/F73/F28/F10/F173).
Запустите игру, откройте панель радионавигации. Отмечайте результат под каждым пунктом.

## A. Отложенные фиксы (требуют прослушивания/просмотра в игре)

- [ ] **F202 — угол ручки спиннера 90°.** Вращайте ручку (Volume/Feedback) в крайние положения. Проверьте: сигнальная полоса/значение на панели соответствует геометрии ручки, или ручка повёрнута на ~90° относительно деления. Если неверно — надо скорректировать `SpinnerHandlerBase.GetAngleOffset()` (Source/UI/SpinnerHandlerBase.cs:26).
- [ ] **F203 — селективность приёмника при QF=20.** Настройтесь на станции-«соседей»: 307/306, 316/315, 266/257 kHz. Слышны ли обе станции одновременно (кросс-ток, гул/помехи на 59–99% громкости)? Необходима ли подстройка `QualityFactor` (Source/Sound/AudioSynthesisEngine.cs:38,53 / Constants.cs)?
- [ ] **F71 — характер шума.** На паузе/в тишине послушайте фоновый шум эфира (атмосферные помехи). Приемлем ли он, или звук «зернистый»/раздражающий (Random per sample — Source/Sound/DspPipeline.cs)?

## B. Регрессия панели

- [ ] Загрузка мода: в логе нет `target methods not found` (pre-flight), нет ошибок `[RadioNavigation]`.
- [ ] Панель открывается, префаб валиден (не сработал отказ загрузки по валидации Main.cs).
- [ ] Toggle (вкл/выкл): при `OFF` тишина; при `ON` — сигналы станций.
- [ ] Ground mode: переключение «наземный/секторный» меняет характер сигнала.
- [ ] Zone: переключение зон меняет частотный диапазон.
- [ ] Volume/Feedback спиннеры: плавное изменение.
- [ ] Позывной станции декодируется (морзе) корректно.
- [ ] Определение позиции (position fix): после получения пеленгов по 2+ станциям выдаётся позиция с ошибкой в разумных пределах.
- [ ] Все 14 станций различимы по частоте/диапазону.

## C. Стабильность

- [ ] **F83 — hot-reload.** Перезагрузите мод/сцену (реинициализация). Нет «зомби»-решений RadioStoryIntegration (мёртвая цепочка G1–G4 — панель не должна от этого зависеть).
- [ ] Утечки событий: многократное открытие/закрытие панели не дублирует обработчики (Double.Subscribe → N подписок).
