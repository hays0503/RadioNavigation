# F206. AudioSynthesisEngine — тики морзе накапливаются по кадрам, а не по сэмплам: при стерео все тайминги замедляются вдвое (latent)

| Поле | Значение |
|------|----------|
| **Приоритет** | P3 (Low) |
| **Область** | Sound · AudioSynthesisEngine · Timing |
| **Файл** | `Source/Sound/AudioSynthesisEngine.cs:35-37, 73-75`; `Source/Logic/SonneController.cs:14` |
| **Дата обнаружения** | 2026-08-01 |

---

## Описание

`ticksPerSample` вычисляется на сэмпл, но аккумулируется по **фреймам** (шаг цикла — `channels`):

```csharp
// AudioSynthesisEngine.cs:35-37
float samplesPerMs = SampleRate / 1000f;   // 44.1
float msPerTick = 50f;                      // тик = 50 мс
ticksPerSample = 1f / (samplesPerMs * msPerTick);   // 1 / 2205 на сэмпл

// AudioSynthesisEngine.cs:73-75
for (int i = 0; i < data.Length; i += channels)    // ← фрейм
{
    tickAccumulator += ticksPerSample;             // ← прибавка «на сэмпл»
```

При `channels == 1` (фрейм ≡ сэмпл) тайминги верны: тик каждые 2205 сэмплов = 50 мс. При `channels == 2` тик происходит каждые 2205 **фреймов** = 4410 сэмплов = **100 мс** — все длительности морзе (точки, тире, паузы, паттерн) растягиваются ровно вдвое.

---

## Влияние

- Latent сегодня: `silentClip` создаётся mono (`SonneController.cs:14` — `channels: 1`), поэтому дефект не проявляется.
- Сработает при любом переходе на стерео-источник/формат: половина скорости морзе, срыв циклов `Callsign`/`Navigation` (паттерн ~133 с вместо ~65 с) — без каких-либо ошибок в логе.
- Не покрыто: **F94** — float drift аккумулятора (другая проблема), **F98** — двойной tick пауз (другая точка).

---

## Сценарий воспроизведения

1. Заменить `silentClip` на стерео (или поднять `channels` в `OnAudioFilterRead`).
2. Морзе-передача замедляется вдвое без сообщений об ошибке.

---

## Исправление

Умножать прибавку на количество каналов:

```csharp
tickAccumulator += ticksPerSample * channels;
```

Либо перейти на индексацию по сэмплам (`i++`) с записью `for c in channels` внутри.

---

## Зависимости

- **F98** — оба дефекта влияют на длительность фаз; при исправлении таймингов перепроверить фазы.
- **F94** — аккумулятор float: переход на double желателен в той же строке.
- **F01/F29** — тики в audio thread: исправление не меняет потоковую модель.
