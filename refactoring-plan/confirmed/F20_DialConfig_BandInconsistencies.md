# F20: DialConfig — несоответствия диапазонов

**Приоритет:** P2 (Medium)
**Область:** Data · DialConfig
**Тип:** Data correctness

---

## Проблема

Два подозрительных момента в конфигурации диапазонов: Band I объявлен в MHz для частот, где исторически были kHz; Bands III и IV перекрываются без объяснения.

---

## Evidence

### 1. Band I: Unit = "MHz" с RangeMin=70, RangeMax=150

DialConfig.cs:28-38:

```csharp
Bands[0] = new BandConfig
{
    Id = "I", Color = "black", RangeMin = 70, RangeMax = 150, Unit = "MHz",
    // ...
};
```

Реальные Consol/Sonne частоты: 255-530 kHz (по историческим данным). 70-150 MHz — это FM-радиовещание, а не Consol. 

Если это маппинг «условных единиц» на циферблате — должно быть документировано. Если это баг — FormatFrequency отобразит `72.4 MHz` вместо правильного `72450 kHz` или подобного.

### 2. Bands III и IV перекрываются в 720-760 kHz

| Band | RangeMin | RangeMax |
|------|----------|----------|
| III (yellow) | 340 | 760 |
| IV (green) | 720 | 1600 |

Диапазон 720-760 kHz определён в двух bands. Если пользователь выберет зону, соответствующую этому диапазону, поведение не определено (какая зона active — зависит от ZoneHandler mapping, не от DialConfig).

---

## Предлагаемое решение

1. Проверить исторические частоты Consol/Sonne. Исправить Unit на kHz.
2. Устранить перекрытие: или сдвинуть границу Band III до 719, или задокументировать как intentional.
3. Добавить единицы измерения в BandConfig (±).

---

## Acceptance Criteria

- [ ] Band I отображается в корректных единицах
- [ ] Нет перекрывающихся диапазонов без документации
- [ ] FormatFrequency корректен для всех 5 bands
