## Описание

Во время инициализации выполняется поиск объекта через `GameObject.Find()` с использованием полного строкового пути.

Такой подход:

- зависит от структуры сцены;
- чувствителен к переименованию объектов;
- не проверяется компилятором;
- требует полного обхода иерархии.

При изменении структуры UI мод перестанет работать без каких-либо изменений в коде.

## Корневая причина

Использование строковых путей вместо получения ссылки через сериализованные поля, DI или кэширование.

## Предлагаемое исправление

Заменить поиск через `GameObject.Find()` на один из вариантов:

- SerializedField;
- Dependency Injection;
- регистрацию объекта во время создания;
- единоразовое кэширование ссылки.

## Зависимости

Нет.
