| **Дата обнаружения** | 2026-08-01 |

---

## Описание

В трёх местах строка содержит пару символов `U+0412 U+00B0` (кириллическая заглавная «В» + знак градуса) вместо одного `U+00B0`:

```csharp
// InformationPanelHandler.cs:342
line += "\n  Dots:" + diag.DotCount + " Bearing:" + diag.CurrentBearing + "В°";
// InformationPanelHandler.cs:382-383
"Fix: " + Math.Abs(lat).ToString("F4") + "В° " + latDir +
" " + Math.Abs(lon).ToString("F4") + "В° " + lonDir + "\n" +
```

Подтверждено hex-проверкой файла (UTF-8: `В°` = `U+0412 U+00B0`).

---

## Влияние

- UI показывает `Bearing: 45В°`, `Fix: 54.1234В° N` — лишний символ перед градусом в основном навигационном readout.
- Косметика, но заметно; в TMP/шрифтах без кириллического глифа может отображаться как «□°» или «?°».
- Не покрыто: **F19/F31** — про конкатенацию/аллокации, не про неверные символьные данные. F161 — округление частоты, другое.

---

## Сценарий воспроизведения

1. Открыть инфо-панель в Sonne-зоне.
2. В строке станции: «Bearing: 123В°»; в блоке фикса: «Fix: 0.0000В° N 0.0000В° E».

---

## Исправление

Заменить литералы на `"\u00B0"` или `"°"` (только `U+00B0`) в трёх местах:

```csharp
line += "\n  Dots:" + diag.DotCount + " Bearing:" + diag.CurrentBearing + "\u00B0";
"Fix: " + Math.Abs(lat).ToString("F4") + "\u00B0 " + latDir + ...
```

---

## Зависимости

- **F200** — блок «Fix:» станет осмысленным после подключения позиции; символьный дефект независим.
- **F161** — соседнее форматирование в `DialConfig` — при чистке текстовых литералов проверить оба.
