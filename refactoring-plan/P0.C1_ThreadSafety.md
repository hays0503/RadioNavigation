# Thread Safety Violation — Shared Mutable Audio State

## Problem

`AudioSynthesisEngine.ProcessAudio()` executes on Unity's audio callback thread via `OnAudioFilterRead`, mutating shared arrays of `StationState[]`, `StationScheduler[]`, `MorseKeyer[]`, and `CarrierGenerator[]`. Simultaneously, the main-thread `SonneController.Update()` and `UpdateStationGains()` read/write those same structures with zero synchronization.

No locks, no double-buffering, no `volatile` keyword. This is a textbook race condition. Under high CPU load, audio thread may interleave with main-thread writes, causing garbled output or NullReferenceExceptions.

### Known Race Paths

| Thread | Operation | File:Line |
|--------|-----------|-----------|
| Audio | `sched.Tick()` — mutates scheduler phase | `AudioSynthesisEngine.cs:86` |
| Audio | `keyers[s].LoadConsol(...)` — reassigns keyer state | `AudioSynthesisEngine.cs:105` |
| Audio | `keyers[s].Advance()` — advances elements, updates counters | `AudioSynthesisEngine.cs:123` |
| Main | `SonneController.UpdateStationGains()` — writes stations[].Gain | `SonneController.cs:337-393` |

## Impact

- **Audio glitches** under high CPU load (crackling, dropouts)
- **NullReferenceException** on audio thread if main-thread frees a scheduler between reads
- **Undefined behavior** with mutable struct state in `StationState[]` — writes via `stations[i].Gain = ...` mutate array element; reads may get torn values across cores

## Recommended Fix

### Short-term (P0)
1. Make shared arrays `volatile`: `private volatile StationState?[] stations;`
2. Wrap main-thread station state mutations in a `lock { }` block that audio thread also checks before sampling: `if (lockTakenTry()) { lock(this) { /* mutation */ } }`

### Medium-term (P1 — blocked by C2 god-class decompose)
Implement **double-buffering**: main writes to buffer A, audio reads from buffer B (and vice-versa). Switch buffers on frame boundary using `Interlocked.Exchange`. This avoids locks entirely.

```csharp
private StationState[] _readBuffer;
private StationState[] _writeBuffer;

void UpdateStationGains() {
    lock(this) { /* mutate writeBuffer only */ }
}

// Audio thread: always reads from readBuffer snapshot
void ProcessAudio(float[] output, int samples) {
    var currentRead = Interlocked.CompareExchange(ref _currentRead, ...);
    for (int i = 0; i < stations.Length; i++) {
        var state = currentRead[i]; // safe concurrent read
    }
}
```

### Long-term
Migrate all station data to immutable snapshots per-frame. Each `UpdateStationGains()` post computes a new read-only array and swaps atomically (see P1 God Object decompose for parallel work).
