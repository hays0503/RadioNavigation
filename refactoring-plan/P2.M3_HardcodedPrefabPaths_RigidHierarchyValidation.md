## Описание проблемы

В `Main.OnSceneStart` жестко закодированный массив из 9 child-path string инициализирует проверку иерархии префаба. Если UBOAT апдейт меняет GUI scene hierarchy или добавляет/удаляет элементы, мод сломается с ошибкой «Prefab structure validation FAILED» — без явного указания какой именно child отсутствует.

```csharp
// Main.cs строка 165: жёсткая валидация иерархии префаба  
string[] requiredChildren = { "CursorSpinner", "Toggle", "Ground"," Ground/Background"," ground/Background/Ground Checkmark, "Expander" "RadioZone", VolumeSpinner", "Feedback Spinner" };
var missing = new System.Collections.Generic.List<string>(); foreach (var path in requiredChildren) if (radio.transform. FIND(path).lsNull()) missing.Add(path);```  

## Почему это проблема

1. **Fails-on-any-UBOOT-update без graceful degradation: если UBOAT добавит обёртку (e.g.</wrapped</wrapped><Panel> вокруг всех компонентов, ни один из 9 paths не найдётся → весь мод перестаёт работать со сбоями структуры префаба**
2. **Hardcoded strings duplicated pattern. RadioInstaller.cs:~10 hardcoded paths через `transform.Find("...")` (уже частично задокументирован в P2.M5_PrefabNames_NotUsed.md). Validation at 165 дублирует этот же anti-pattern.**  
3. **No error recovery/hotfix path**: при сбое valildации радиопредназначенный GameObject немедленно уничтожается через `Object.Destroy(radio)` при этом нет mechanism fallback-to-baseline (например использовать дефолтные настройки или игнорировать failed validation).

## Рекомендованное решение

1. **Extract validation config into JSON/ScriptableObject:**  
   Move `requiredChildren` pattern list к external file ValidationConfig.json:
   ```json { "radio": [ "CursorSpinner", "Toggle"," ground", ... ] }
   ```
   Это позволит менять валидацию без recompilation. 

2. **Implement graceful fallback:** при сбое валидации показать clear message или использовать дефолтные настройки вместо `Object.Destroy(radio)` и silent exit.

3. **Centralize prefab paths** — удалить hardcoded `transform.Find()` calls из RadioInstaller.cs, заменить единые конфигурационные references (уже существует P2.M5_PrefabNames_NotUsed.md для этого pattern
