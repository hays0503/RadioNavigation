## What to add — verified facts only

### Project identity
- C# .NET Standard 2.0 Unity mod for UBOAT game (WW2 submarine simulator)
- Adds Consol/Sonne radio navigation beacon panel with audio synthesis and position fixing
- Namespace: `UBOAT.Mods.RadioNavigation`
- Author: testui, Version: 2.0

### Build system (agent would guess wrong without this)
- Uses raw `csc.exe` via `build.ps1`, NOT `dotnet build` or MSBuild SDK workflow
- Requires local UBOAT game install path (default Steam location) for Unity/game DLL references
- Command: `powershell -File build.ps1 [-GamePath <path>] [-Configuration Debug|Release] [-OutputDir .]`

### Architecture (non-obvious from filenames)
- **Entry point**: `Source/Logic/Main.cs` — implements `IUserMod`, Harmony patching, DI injection, prefab instantiation
- **Harmony patches** target: `RadioStory.ContinueStory`, `Locale.RetrieveString`, `RadioStory.OnDecisionSelected`, `RadioStory.OnStopped`
- **DI framework**: UBOAT's custom `DWS.Common.InjectionFramework` (requires Reflection permission in Manifest.json)
- **UI**: Unity uGUI prefabs loaded from AssetBundle (`Bundles/testui`) — prefab hierarchy must match hardcoded paths in Main.cs line 165
- **Four source namespaces**: Data (static configs), Logic (core simulation), Sound (DSP audio synthesis), UI (MonoBehaviour handlers)

### Gotchas / constraints agents would miss

- No lint, no formatter, no `.editorconfig` — the refactoring plans propose adding one
- Harmony patches silently fail if UBOAT game version changes (target methods may be renamed/removed) — check pre-flight log on mod load
- AssetBundle must exist at `Bundles/testui` relative to mod root; Unity editor build process creates it
- `#if DEBUG` blocks in Main.cs dump hierarchy but are stripped from Release builds
- Graphify knowledge graph is AST-based and dirty files are expected after incremental updates
